# Коли світло? — пошук черги ГПВ за адресою

Маленький веб-застосунок: вводиш адресу (можна скорочено — `Шев 10`, `Незалежн 20`,
навіть російською — `Европейская 5а`) і одразу бачиш, у якій черзі/підчерзі будинок
і з котрої до котрої години відключення.

Дані беруться з офіційної сторінки ДПЕМ ПрАТ «Атомсервіс»:
<https://info.dpem.mk.ua/off_graf.html>

Знайдену адресу можна зберегти (☆), а адресу, якої немає в переліках ДПЕМ, — додати
вручну з відомою підчергою («Мої адреси», зберігаються в браузері).

Ще:

- **«Звірити графіки»** — перевіряє графік напряму з сайтом ДПЕМ і пише, чи він збігається
  або що саме змінилося;
- **історія пошуку** ліворуч (на телефоні — кнопка в шапці) — повними назвами
  («бульвар Шевченка, 10», а не «шев 10»);
- **«Усі черги»**: натисніть на підчергу — розгорнеться перелік адрес, які з нею вимикаються,
  і фідери (підстанція, № фідера, тип перемикання);
- **«Персоналізація»** (кнопка в шапці): 8 тем оформлення, «Мої мікрорайони» (межі з
  OpenStreetMap — на головній видно, які підчерги живлять мікрорайон і коли там немає світла),
  віджет на телефон;
- **віджет і сповіщення на телефоні**: Android — застосунок
  [KolySvitlo.apk](https://github.com/raitodano/koly-svitlo/releases/latest/download/KolySvitlo.apk)
  (папка `android/`), iPhone — скрипт для Scriptable (`static/scriptable/KolySvitlo.js`).
  Сповіщення приходить на початку помаранчевої півгодинки — приблизно за 30 хв до відключення.

Докладно, як усе влаштовано: **[КАК_ЭТО_РАБОТАЕТ.md](КАК_ЭТО_РАБОТАЕТ.md)**.

## Онлайн

**<https://raitodano.github.io/koly-svitlo/>** — працює з будь-якого пристрою.
GitHub Actions (`.github/workflows/pages.yml`) за розкладом забирає свіжий графік
з сайту ДПЕМ і перевидає сторінку. GitHub виконує розклад «за можливості» й інколи
пропускає запуски на години, тому сторінка звіряється з ДПЕМ і сама: кнопкою
«Звірити графіки» або автоматично, якщо копія старша 40 хв. Сайт ДПЕМ не дозволяє
браузеру читати себе з іншого домену (немає CORS), тож сторінка ДПЕМ читається через
публічний сервіс [r.jina.ai](https://jina.ai/reader/) — береться лише масив графіка.
Якщо в репозиторії 60 днів немає активності, GitHub вимикає розклад — його вмикає
кнопка «Enable workflow» на вкладці Actions.

## Програма для Windows (KolySvitlo.exe)

**[Завантажити KolySvitlo.exe](https://github.com/raitodano/koly-svitlo/releases/latest/download/KolySvitlo.exe)**
(остання версія з [Releases](https://github.com/raitodano/koly-svitlo/releases)).

Один файл, Python ставити не потрібно. Запуск — подвійний клік: відкриється браузер,
а у вікні програми буде адреса для телефона, наприклад `http://192.168.1.3:8765`
(телефон має бути в тій самій Wi-Fi мережі). При першому запуску Windows спитає
дозвіл брандмауера — дозвольте для **приватних** мереж. Закрити вікно — зупинити.

Зібрати самому:

```bash
powershell -ExecutionPolicy Bypass -File build_exe.ps1
```

Результат — `dist\KolySvitlo.exe`. Параметри: `--port 8765`, `--local-only`
(лише цей комп'ютер), `--no-browser`.

Новий реліз: відправити тег `v*` — GitHub Actions (`.github/workflows/release.yml`)
збере exe на Windows, перевірить запуск і прикріпить файл до релізу:

```bash
git tag v1.0.1
```

```bash
git push origin v1.0.1
```

## Запуск з коду

Потрібен лише Python 3.9+ (без сторонніх бібліотек).

```bash
py server.py
```

Відкрити <http://localhost:8765> (`--lan` — доступ з інших пристроїв у мережі).
Частота перечитування сайту — змінна `CACHE_TTL` (секунди, за замовчуванням 300).
Статична версія для хостингу: `py build_static.py site`.

Тести:

```bash
py -m unittest discover -s tests
```

## Як це працює

- `dpem.py` завантажує сторінку й розбирає дві речі:
  - JS-масив `records` — графік на кожну дату: 12 підчерг (1-І … 6-ІІ) × 48 півгодинних
    слотів. Значення: `0` світло є, `1`/`3` перемикання (до 30 хв), `2` світла немає,
    `4` можливе відключення;
  - таблиці «Підчерга N-І/ІІ» з переліком вулиць і будинків — розбираються на записи
    «населений пункт / тип / вулиця / будинки» (з урахуванням «смт. Костянтинівка: …»,
    діапазонів `37-39`, літер `54-Б` тощо).
- `server.py` віддає `static/` і `/api/data` (JSON), кешує дані на 5 хв і зберігає
  останню вдалу копію в `cache/last.json`, щоб працювати, навіть якщо сайт ДПЕМ недоступний.
- `build_static.py` — те саме, але у вигляді статичних файлів + `data.json` (для GitHub Pages).
- `static/app.js` — пошук у браузері:
  - нечіткий збіг за початком слова з допуском на 1–2 помилки («Шевченко» ≈ «Шевченка»);
  - словник російських основ («независимости» → «незалежності», «цветочный» → «квітковий»);
  - номер будинку: точний збіг, діапазон, «схожий номер» (10 ↔ 10А) і вулиці, де номери
    не вказані;
  - якщо адреса є в кількох підчергах — показує всі з номерами фідерів (будинок може мати
    два вводи від різних ліній; які під'їзди від якої лінії, ДПЕМ не публікує);
  - для сьогоднішньої дати — статус «зараз є/немає світла» і коли наступне відключення
    (за київським часом).

## Обмеження

- Переліки на сайті заповнюються вручну, тож розбір евристичний: рідкісні записи можуть
  розпізнатися неідеально (повний текст рядка завжди доступний у картці — «Повний перелік
  адрес цієї лінії»).
- Якщо сайт ДПЕМ змінить верстку, `dpem.py` повідомить про помилку, а сервер продовжить
  віддавати останню збережену копію.
