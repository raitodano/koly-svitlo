# Коли світло? — пошук черги ГПВ за адресою

Маленький веб-застосунок: вводиш адресу (можна скорочено — `Шев 10`, `Незалежн 20`,
навіть російською — `Европейская 5а`) і одразу бачиш, у якій черзі/підчерзі будинок
і з котрої до котрої години відключення.

Дані беруться з офіційної сторінки ДПЕМ ПрАТ «Атомсервіс»:
<https://info.dpem.mk.ua/off_graf.html>

## Запуск

Потрібен лише Python 3.9+ (без сторонніх бібліотек).

```bash
py server.py
```

Відкрити <http://localhost:8765>. Порт змінюється змінною `PORT`, частота
перечитування сайту — `CACHE_TTL` (секунди, за замовчуванням 300).

Тести:

```bash
py -m unittest discover -s tests
```

## Як це працює

- `dpem.py` завантажує сторінку й розбирає дві речі:
  - JS-масив `records` — графік на кожну дату: 12 підчерг (1-І … 6-ІІ) × 48 півгодинних
    слотів. Значення: `0` світло є, `1`/`3` перемикання (до 30 хв), `2` світла немає,
    `4` можливе відключення;
  - таблиці «Підчерга N-І/ІІ» з переліком вулиць і будинків — розбираються на записи
    «населений пункт / тип / вулиця / будинки» (з урахуванням «смт. Костянтинівка: …»,
    діапазонів `37-39`, літер `54-Б` тощо).
- `server.py` віддає `static/` і `/api/data` (JSON), кешує дані на 5 хв і зберігає
  останню вдалу копію в `cache/last.json`, щоб працювати, навіть якщо сайт ДПЕМ недоступний.
- `static/app.js` — пошук у браузері:
  - нечіткий збіг за початком слова з допуском на 1–2 помилки («Шевченко» ≈ «Шевченка»);
  - словник російських основ («независимости» → «незалежності», «цветочный» → «квітковий»);
  - номер будинку: точний збіг, діапазон, «схожий номер» (10 ↔ 10А) і вулиці, де номери
    не вказані;
  - якщо адреса є в кількох підчергах — показує всі (будинок може живитися від кількох ліній);
  - для сьогоднішньої дати — статус «зараз є/немає світла» і коли наступне відключення
    (за київським часом).

## Обмеження

- Переліки на сайті заповнюються вручну, тож розбір евристичний: рідкісні записи можуть
  розпізнатися неідеально (повний текст рядка завжди доступний у картці — «Повний перелік
  адрес цієї лінії»).
- Якщо сайт ДПЕМ змінить верстку, `dpem.py` повідомить про помилку, а сервер продовжить
  віддавати останню збережену копію.
